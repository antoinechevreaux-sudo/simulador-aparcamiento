# Simulador de aparcamiento

App web (index.html). Incluye un teléfono virtual con Ángulo de Maniobra (angulo-sim.js) para ajustar esa app en el simulador.

GitHub Actions compila el APK de Android en cada cambio en `main` (carpeta `android/`) y lo publica en Releases:
https://github.com/antoinechevreaux-sudo/simulador-aparcamiento/releases/latest/download/Aparcar.apk
